# Playwright MCP

- Type: MCP server
- Domain: coding
- Source: https://github.com/microsoft/playwright-mcp
- Status: to-evaluate
- Use when: automating browser interaction, UI smoke tests, accessibility-snapshot inspection, and web app debugging.

## Notes

Compare with Chrome DevTools MCP. Playwright MCP may be better for repeatable interaction and UI smoke tests; Chrome DevTools MCP may be better for deep debugging of console, network, and performance behavior.
