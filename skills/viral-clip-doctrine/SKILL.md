# Viral Clip Doctrine

投流短视频的**决策与方案层**：拿到素材和客户诉求，给出可交付的剪辑方案。**不执行剪辑**——把方案交给谁去剪（人 / 云剪 API / 混剪算子），是本 skill 之外的选择。

## 分工原则（先建立）

一条投流片的产出是**神经-符号复合**过程：

- **LLM 干局部打分**：这段素材和主题多相关、情绪多强、画面多能打。
- **规则/算法干全局约束**：一对一匹配、时长逼近、合规过滤、"事不过三"。
- **别让 LLM 干算术和全局最优**——它会把 `30+45+120+90` 算错，会让三段文案抢同一个高分空镜。

违反这条分工，产出就会同时具备"看起来还行"和"经不起投放"两个特征。

## 输入与输出

**输入**：
- 素材（一到多份）：长直播录像、口播原片、产品图文包、UGC 采集片段。
- 客户档位（三选一）：矩阵跑量 / 品牌向 / 精细人设。
- 目标（可选）：主推 SKU、投放平台、预期时长、竞品参考。

**输出**（一份文档，缺项要显式标注为"待补"，不要静默省略）：

1. **客户分层判断**：命中哪一档，理由一句话。
2. **钩子方案**：前 3 秒的具体开法，标出命中的高流量要素。
3. **分镜时间轴**：每段 `[起止时间] 画面 / 台词 / 气口标记 / BGM cue`。
4. **包装清单**：字幕位置、花字（≤3）、变速段、转场音效。
5. **合规检查**：同质化风险、敏感内容标记、平台预审可能命中的点。
6. **剪辑难点**：需要人工介入或算子难以处理的段落。

## 六段管线

### 1. 定档：客户分层

先判定客户档位，后续所有选择都跟着变：

| 档位 | 典型客户 | 核心诉求 | 质量下限 |
|---|---|---|---|
| **矩阵跑量** | 快鱼、源氏木语等品牌矩阵号；ISV 服务商下游 | 产能 >> 质量，批量投流 | 合规 + 钩子过关即可 |
| **品牌向** | 中高端品牌方 | 品牌调性，生成+剪辑并行 | 需保留品牌视觉资产的完整度 |
| **精细人设** | 二手车服务商、口播 KOL、生活服务 | 从全天素材抓高光，做人设 | 叙事逻辑连贯，去掉工具痕迹 |

**跨档禁忌**：不要把品牌向的调性诉求套到矩阵跑量档去做慢节奏；也不要在精细人设片里塞满花字。

### 2. 定钩子：前 3 秒

投流片的第一战场是前 3 秒，钩子决定用户是否停留。**高流量钩子四要素**（能命中一条即算合格，命中两条以上算强钩子）：

- **反差**：预期与结果的落差（"你以为的 vs 实际的"）。
- **偏离常识**：违反直觉的画面/结论。
- **争吵**：冲突/对立/情绪激烈。
- **情绪激动**：狂喜、愤怒、震惊——不是台词说自己激动，是画面本身激动。

**钩子公式随平台热点动态更新**：这份清单是当前的行业共识，不是永恒定律；跑一段时间要重新校准。

### 3. 拉气口：节奏骨架

**气口** = 台词/剪辑之间的呼吸间隙。它是剪辑的节奏灵魂，不是废料。

| 内容类型 | 气口策略 |
|---|---|
| 高燃、跑量、直播切片 | 密集气口，卡拍点 |
| 瑜伽、生活服务、慢客单 | 刻意保留适当气口，弱化"人工剪辑感" |
| 口播、长实拍 | 按叙事节奏留气口，不要为了压时长把气口全砍掉 |

**反模式**：把所有内容都按"高燃密气口"处理——瑜伽片会变得神经质，二手车口播会变得像销售洗脑。

### 4. 指派：空镜与文案的全局匹配

这是最容易翻车的一步。当你有 M 段文案要配空镜，N 个候选空镜可用时——

**不要用贪心**：每段文案独立挑最高分空镜，会导致高分空镜被前几段抢完，后面的段落只能拿次优或空缺。这是**局部最优 ≠ 全局最优**的经典塌方。

**正确做法**：
1. 让 LLM 对 `文案 × 空镜` 两两打分，给出打分矩阵 `S[i][j]`。
2. **在打分矩阵上求全局最优的一对一匹配**（这是经典的 Assignment Problem，用匈牙利算法 / 最小费用最大流 / LP 松弛任一均可，规模小时 O(n³) 完全够用）。
3. 把求解交给算法，不要让 LLM 自己"感觉"全局哪个更好。

**为什么必须这么做**：LLM 强在"这两个匹配吗"这类局部语义判断，弱在"哪个组合总体最优"这类需要枚举/回溯的全局搜索。分工清楚，产出才稳定。

### 5. 收敛：时长压到目标

营销投流片默认时长 **≤ 3 分半**（这是当前抖音投流的通用甜蜜点，超过 3 分半的完播率会显著掉）。

长素材（几十分钟到十几小时）收敛到目标时长，本质是**背包问题变种**：

- 每段候选片段有：时长 `t_i`、内容关联度打分 `score_i`（LLM 打）、是否必选（钩子/结尾/关键卖点为必选）。
- 目标：`Σ t_i ≈ T_target`，同时 `Σ score_i` 最大，且所有必选片段都在。

**推荐做法**（**残渣 DP** 两阶段）：
1. **主链路**：先把必选片段和高分片段占位，得到一个粗略骨架。
2. **残渣填缝**：剩余时长预算再跑一个精确 DP，从次级候选里挑合适的碎片补齐。

**不要**让 LLM 自己算"选这几段加起来是 3 分 24 秒"——它会算错，而且不同 run 结果不稳定。

### 6. 包装：字幕 / 花字 / 变速 / BGM

| 元素 | 规则 |
|---|---|
| **字幕位置** | 遵循黄金分割区；不同平台"引导按钮"位置不同，字幕摆放要错开按钮区，不然会被点点点跳走。 |
| **花字数量** | **事不过三**——高端品类（豪华车、奢品）花字 ≤ 3 个，多了廉价感；生活服务/搞笑类可放宽。 |
| **变速** | 真人实录统一 1.08–1.1× **无感变速**（观感基本无差别，但压出 8-10% 时长）；曲线变速要跟拍摄运镜配合，不然会晕。 |
| **BGM** | **热歌优先级 > 内容匹配度**。平台当期热歌带来的流量增益，远大于"BGM 和内容主题多契合"。别为了"更贴主题"选一首冷歌。 |
| **音效** | 转场/花字配套音效**用预设**，不要让 LLM 现场挑，随机搭配翻车率高。 |

### 7. 合规：投流预审

在方案交付前跑一遍合规检查：

- **同质化**：抖音/TikTok 对同质化内容检测严苛。矩阵号跑量时**必须**通过模板变体、素材替换、剪辑节奏差异化规避——一旦被判违规，账号权重直接被打下去。
- **敏感内容**：事故车、医疗表述、财经承诺、涉政、擦边——**提前消音、打码、替换文案**，不要指望平台"应该不会查到"。
- **钩子边界**：情绪激动 ≠ 谩骂；反差 ≠ 虚假宣传。钩子命中要素时同时过一遍平台社区公约。

预审规则会随平台策略变化。方案里对**灰区内容**要显式标注"需人工复核"，不要替客户拍板。

## 反模式（一票否决）

看到方案里出现这些，直接打回重做：

- **贪心配空镜**：没有全局最优的说法，只有"每段文案独立挑分最高"。
- **LLM 算总时长**：让 LLM 自己保证片子是 3 分半。
- **花字堆料**：豪华车/奢品片子塞 8 个花字。
- **BGM 强行贴主题**：为了"更契合"选一首完全没听过的曲子。
- **钩子写在标题不写在画面**：前 3 秒画面平淡，指望用户看到标题就停留。
- **矩阵号不做差异化**：50 个号发同一份素材同一个剪辑，被判同质化后集体降权。
- **合规灰区静默处理**：知道有风险但方案里不标注，交付后出事甩锅。

## 使用姿势

**评审模式**（用户给了一份已有剪辑方案）：按六段管线逐项核对，报"命中/漏掉/风险点"，不要重写整份方案。

**生成模式**（用户给了素材+客户档位）：走完六段管线，产出完整方案文档。素材信息缺失时，先列出"需要补充的信息清单"，不要靠猜。

**混合模式**（既有草稿又要优化）：先用评审模式定位问题，再对指出的段落做生成，避免整份推翻。

## 客户飞轮（背景信息，不是主流程）

投流不是一次性交付。**运营飞轮**：投流拿到用户咨询 → 销售提炼用户高频问题 → 作为下一轮拍摄主题 → 再投流。方案输出时如果能顺手标出"这个片子适合作为哪类咨询的引流点"，会大幅提升客户复用率。
