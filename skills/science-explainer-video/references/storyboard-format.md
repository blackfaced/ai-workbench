# 分镜表格式

分镜连接科学断言、旁白和代码。用户只要分镜就交付分镜；已授权整片时按分镜继续制作，只有用户要求先审稿时才等待确认。

## 总览表

记录目标时长、帧率、画幅和有声/无声。每镜包含稳定 ID、起止时间、旁白摘要、画面和动画、实现提示及科学断言 ID；完整台词另附。

| # | 起止 / 时长 | 旁白摘要 | 画面与动画 | 实现提示 / 断言 |
| --- | --- | --- | --- | --- |
| S01 | 0–3s / 3s | 一个问题 | 显示待解释的现象 | Scene 类或组件 / C01 |

时间线检查（用脚本计算，不心算）：

1. 首镜从 0 开始，相邻镜头首尾相接；每镜时长为正，总和等于目标时长。
2. 秒数转换为帧时记录舍入，累计误差不超过约定的帧预算；以实际成片帧数复核。
3. 镜内动画的起止与旁白锚点落在该镜范围内；末个动作加停留时间覆盖到镜头结束。
4. 试读/实际配音超时时删减或重新分配镜头，同时更新目标时长。保留 2–3 秒的理解停顿要算入总时长。

## 60 秒示例：为什么快速幂快（单概念短版）

采用小例子 `2^13 mod 97` 展示二进制前缀的处理，避免展示巨大整数。默认 9:16；同屏一个算式、一组数字。

| # | 起止 / 时长 | 旁白 | 画面与动画 | 实现提示 / 断言 |
| --- | --- | --- | --- | --- |
| S01 | 0–3s / 3s | 算幂，要一直乘吗？ | 亮出 `2^13 mod 97` | 标清“求余数” / C01 |
| S02 | 3–11s / 8s | 只求二的十三次方除以九十七的余数。连续乘，步数跟着指数增长。 | 连乘点列，随后收起 | 朴素累乘基线 / C01 |
| S03 | 11–23s / 12s | 十三写成二进制一一零一。从最高位开始，先放入一个二。 | `13 → 1101`，突出首位和初值 2 | 当前前缀为 1 / C01 |
| S04 | 23–38s / 15s | 每读一位先平方；读到一，再乘二。每步取余，结果依次是八、六十四、四十四。 | 余下三位逐位亮起，前缀 `1→3→6→13`；余数 `2→8→64→44` | 每位一次平方，1 位额外相乘 / C01 |
| S05 | 38–52s / 14s | 三次平方加两次相乘，共五次模乘。这里只计步骤，大整数每一步的成本另算。 | 计数 `3+2=5`；显示“计次数，不计位成本” | 运行示例核验 / C01 |
| S06 | 52–60s / 8s | 关键是按二进制组合结果。换个指数，自己数一数。 | 回到 `1101` 并保留结论 | 总时长 60s / C01 |

按实际读法试读；若超时，优先缩短解释，不把句尾截掉。上表是一条可读的时间线草稿，不声称已录制或已验证音画同步。

### S04 详注（15 秒）

- 0–4s：读第二位 1，平方再乘 2，余数为 8；旁白“先平方”落在本镜约 1s。
- 4–8s：读第三位 0，只平方，余数为 64。
- 8–12s：读第四位 1，平方再乘 2 后取模，余数为 44。
- 12–15s：保留 `2→8→64→44`，让观众检查对应关系。
- 关键帧：每次只高亮当前前缀、当前位与当前结果；公式和字幕使用不同区域。

## 5 分钟扩展（300 秒）

同一主题扩展推导与验证，避免增加第二个核心结论。各段时长：`[12, 35, 25, 60, 55, 55, 35, 23]`，合计 300 秒。

| 镜头 | 时长 | 内容 |
| --- | --- | --- |
| S01 | 12s | 提问：求大指数模幂为何不必逐次累乘？ |
| S02 | 35s | 朴素累乘基线，明确计数口径 |
| S03 | 25s | 用 13 的二进制表示建立直觉 |
| S04 | 60s | 前缀指数翻倍对应平方；当前位为 1 时再乘底数 |
| S05 | 55s | 逐步算 `2^13 mod 97`，独立核对结果 44 |
| S06 | 55s | 展示并运行随包模幂例子，检查边界输入 |
| S07 | 35s | `10^9` 的 30 位与本实现 41 次模乘，区分次数和位复杂度 |
| S08 | 23s | 回顾适用条件与一个新的练习指数 |

长版 S04 的 60 秒可分为 0–15s 前缀解释、15–30s 平方推导、30–50s 处理 0/1 两分支、50–60s 回顾与停留。长短版详注不可混用。
