## 可运行例子：二进制模幂

运行 [modular_power_example.py](../assets/modular_power_example.py)：

```bash
python3 assets/modular_power_example.py
```

示例使用从高位到低位的算法。对正指数，先把结果初始化为底数，再处理余下的二进制位：每一位平方，遇到 1 再乘底数，每次都取模。循环不变量是“当前结果等于底数的已处理前缀指数次幂，模 m”。指数为 0 时单独返回 `1 mod m`。

- `2^13 mod 97 = 44`，本实现做 3 次平方、2 次额外相乘，共 5 次模乘。
- `10^9` 有 30 个二进制位，其中 13 个为 1。本实现做 29 次平方、12 次额外相乘，共 41 次模乘；“30 位”不等于“30 次乘法”。
- 验证用 768 组小输入和 Python 内置 `pow` 对照，再检查上述案例。`pow` 仅作结果的独立参照，不用它推断示例算法的运算次数。[Python 官方 `pow` 说明](https://docs.python.org/3/library/functions.html#pow)
- 这里只计模乘的次数，不声称每次大整数乘法和取模都是常数时间。直接输出完整 `2^(10^9)` 与计算其模 97 的余数是不同任务；97 只用于教学，不构成密码安全建议。

用不同快速幂实现时重新计数，不把该实现的 41 次推广成所有算法的固定值。
