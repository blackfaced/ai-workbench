# Domain docs

This repository has a single domain context.

## Before exploring

- Read root `CONTEXT.md` for the project glossary and domain language.
- Read relevant decisions under `decisions/` before proposing or changing architecture.
- Read `AGENTS.md` for repository-wide collaboration rules.

Proceed silently when a referenced document is absent. Use the glossary's vocabulary in issue titles, acceptance criteria, and technical proposals. Surface any conflict with an existing decision instead of silently overriding it.
